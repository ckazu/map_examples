Hex Map Simulator

獲得セル数： 0
支配領域： 0
拠点セル数： 0

操作方法：

  • クリック＆ドラッグ： セルを獲得
  • ダブルクリック（獲得済みセル上）： 拠点セル（黄色）を作成
  • ダブルクリック（拠点セル上）： 拠点セルのレベルアップ（最大4）
  • Control + クリック（拠点セル上）： 拠点の接続開始
  • Control + Shift + クリック（拠点セル上）： 三角形接続のための3点目の追加
  • Shift + クリック（拠点セル上）： 拠点セルのレベルダウン
  • Shift + クリック（獲得済みセル上）： セルの獲得を取り消し

拠点セルのレベル：

  • レベル1（黄色）： 基本拠点セル
  • レベル2（オレンジ）： 隣接セルを自動獲得
  • レベル3（赤）： 半径2範囲のセルを自動獲得
  • レベル4（ダークレッド）： 半径3範囲のセルを自動獲得
モード： 獲得モード
接続： なし
