# Hex Map Simulator

六角形グリッドを使った領域制圧シミュレーターです。

## 概要

Hex Map Simulatorは、六角形のグリッドマップ上で領域を征服し、制圧するためのウェブブラウザアプリケーションです。クリックやドラッグ操作により六角形を征服し、選択した六角形を基点に領域を制圧することができます。

## 機能

### 基本機能

- 六角形グリッドの表示
- クリックとドラッグによる六角形の征服
- 征服した六角形を選択して領域を制圧
- 制圧方法は2種類：
  1. ライン制圧（2点間を結ぶライン）
  2. 三角形制圧（3点で形成される三角形内）
- 征服数と制圧数のカウンター表示

### 特徴

- 征服した六角形は青色で表示
- 制圧した領域は青色に緑色のマーカーで表示
- 選択中の六角形は黄色でハイライト
- 選択した頂点をクリックすることで選択解除可能
- 3点選択後に1点を解除すると、残り2点でライン制圧に自動的に切り替わる
- 境界線にかすっている六角形も制圧対象に含まれる

## 操作方法

### 六角形の征服

1. 未征服の六角形（灰色）をクリック
2. ドラッグして隣接する六角形を連続して征服
3. 征服された六角形は青色に変わる

### 領域制圧（ラインモード）

1. 征服済み六角形（青色）をクリックして選択（黄色に変わる）
2. 別の征服済み六角形をクリックして2点目を選択
3. 2点間を結ぶライン上および交差する六角形が制圧される（青色に緑マーカー）

### 領域制圧（三角形モード）

1. 征服済み六角形を2点選択（上記と同様）
2. 3点目の征服済み六角形を選択
3. 3点で形成される三角形内および境界に交差する六角形が制圧される

### 選択の解除・変更

- 選択済みの頂点をクリックすると、その頂点の選択が解除される
- 3点選択時に1点を解除すると、残り2点でライン制圧に切り替わる
- 「Cancel Selection」ボタンで現在の選択をすべて解除
- 「Reset Map」ボタンでマップをリセット（すべての征服と制圧が解除される）

## 制約事項

- 最大3点まで選択可能
- 未征服の六角形は選択できない（先に征服する必要がある）
- 3点が一直線上にある場合は、三角形ではなくライン制圧として扱われる

## 技術仕様

- HTML5 Canvas APIを使用した描画
- 立方体座標系（x, y, z where x + y + z = 0）による六角形の表現
- JavaScript ES6+による実装
- 外部依存ライブラリなし（Pure JavaScript）
